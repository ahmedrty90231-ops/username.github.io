# Blocka — браузерный клон Minecraft

**Строй. Исследуй. Выживай.** Воксельная песочница, работающая прямо в браузере — без установки, на Three.js.

## Запуск

Открой `index.html` — это главное меню. Игра: `game.html`.
На GitHub Pages сайт поднимется автоматически из корня репозитория.

Локально лучше запускать через любой статический сервер (для корректной загрузки ассетов):

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

## Возможности

- **Процедурный мир** с биомами (равнины, лес, пустыня, снега), горами, озёрами, пещерами и алмазной рудой
- **Выживание**: здоровье, голод, урон от падения, утопление; еда из листвы (яблоки)
- **Добыча и стройка**: ломай блоки (ЛКМ), ставь (ПКМ), инвентарь на 9 слотов
- **День/ночь** (10-минутный цикл), солнце, луна, звёзды, облака, туман
- **Ambient Occlusion** на гранях блоков — мягкие тени в углах
- **Полёт** (творческий режим): двойной Пробел
- **Сохранение мира** в localStorage + автосейв каждые 20 секунд
- **Тач-управление** для телефонов (джойстик + кнопки)
- Русский / English интерфейс
- Процедурные звуки на WebAudio (без аудиофайлов)

## Управление

| Клавиша | Действие |
|---|---|
| WASD | Движение |
| Пробел | Прыжок (×2 — полёт) |
| Shift / Ctrl | Красться / бег |
| ЛКМ / ПКМ | Ломать / ставить (или съесть еду) |
| 1–9, колесо | Выбор слота |
| Esc | Пауза |
| F | Полный экран |

## Структура

```
index.html          главное меню
game.html           игра
js/engine/          движок: world, player, textures, hud, sound, i18n …
js/vendor/          three.js r128
assets/ui/          HUD-ассеты (сердечки, еда, хотбар — из блок-арта Blocka)
assets/menu/        логотип, фон меню, превью обновления
```

Сид мира можно задать в «Одиночная игра → Создать новый мир».
